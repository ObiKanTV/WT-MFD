# Changelog

## 0.1.0-preview (2026-10-11)

First public preview.

- Four MFD pages: FLT (flight data and attitude indicator), ENG (fuel, burn rate, bingo, engines), MAP (the game's map with grid, waypoints, targets and objectives), SYS (lamps, objectives, kill feed and chat)
- Own borderless app window (WebView2); the MFD also works in any browser or on a tablet
- Stream Deck plugin with live key labels, plus API Ninja support without the plugin
- Waypoints, next target and manual target with range, bearing and ETA
- Rocket hold-over estimate for aircraft without a rocket aiming computer
- Team call banners, with grid squares marked on the map
- Air Simulator reward cycle timer (15-minute payout cycles, landing bonus, kills per cycle), with CYC RST and a live Stream Deck key
- Match logs for debugging
