First public preview of WT-MFD: a second-screen MFD for War Thunder, driven by a Stream Deck. Built for a home simulator cockpit, so flight data sits next to the game instead of on top of it.

> **Unofficial and not affiliated with Gaijin Entertainment. Use at your own risk.** WT-MFD only reads the data War Thunder publishes on `localhost:8111` for its own browser map. It does not modify the game, read its memory or automate anything, but Gaijin has not approved it and may treat tools that turn game data into extra information as an unfair advantage, which can lead to account restrictions. See the [disclaimer](https://github.com/ObiKanTV/WT-MFD#disclaimer).

## What's in it

- FLT, ENG, MAP and SYS pages
- Stream Deck plugin with live key labels
- Waypoints, next target and manual target with range, bearing and ETA
- Rocket hold-over estimate for aircraft without a rocket aiming computer
- Team call banners with grid squares on the map
- Air Simulator reward cycle timer: counts down to each 15-minute payout, tells you when landing pays the bonus, and restarts itself when you respawn

## Install

1. Install the .NET 8 runtime: `winget install Microsoft.DotNet.AspNetCore.8`
2. Unzip `WT-MFD-v0.1.0-preview-win-x64.zip`, double-click `Start MFD.cmd`, then start War Thunder.
3. Optional: set `Callsign` in `app\settings.json` and run `streamdeck\Install Stream Deck plugin.cmd`.

Full instructions are in the [README](https://github.com/ObiKanTV/WT-MFD#readme).

## Known limits

- Windows only.
- The reward cycle rules come from community measurements, not from Gaijin. Use CYC RST if the timer misses a spawn.
- War Thunder reports different values per aircraft, so some fields show `---` on some aircraft.
